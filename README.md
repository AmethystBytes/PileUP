# 📦 PileUP Package Management System

⚠️**DISCLAIMER**⚠️ AI was used in this project, but *only as an assist tool*. 95% of the code was hand-written by me, but if there is a very complicated error, I will use AI. AI should not be used to create whole programs start to finish on its own.


**What is PileUP?** 

PileUP is a simple and lightweight package/parcel management system, designed for easy of use. It relies of a simple CLI window to interact with the program. It uses python as its main language combined with JSON for its libraries. This program also has the benefit of needing no dependencies from pip, making it even simpler for install.

**Should I use this in a high-scale project?** 

Absolutely not. I made this project over the course of 2 days, as a beginner in python, and as of now it is still in early stages. I would also refrain from using this even on a low-scale, if possible.

**Features** 

*PileUP SafetyTeam/ConfirmClean*: PileUP SafetyTeam is a tool that automatically checks all the functions of PileUP, and alerts you if something is wrong. ConfirmClean is a tool that makes sure SafetyTeam's tests don't break the system.

*PileUP PackID*: (Alpha Stages) PileUP's own package identification system. It assigns each package a number between 10000000-99999999 to identify each package. Eventually, you will have access to PackID externally via an API, but that feature unfortunatly isn't available yet.

**Installation** 

All you need is python 3.6 or higher (as far as I'm aware). Just download the program and launch it in a terminal/console.
